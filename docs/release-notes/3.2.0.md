# KotStep 3.2.0 — Compose Multiplatform Launch

**KotStep is now a Compose Multiplatform library.** The V3 DSL (`KotStep` / `KotStepScope` /
`KotStepStyle`) runs on **Android, iOS, Desktop (JVM), and Web (Wasm)** from the same
`commonMain` source set. This is a milestone release: the artifact shape changes from an
Android-only AAR to a fully published multiplatform module.

## What's new

- **KMP targets**: `androidTarget`, `jvm("desktop")`, `wasmJs`, `iosArm64` / `iosX64` /
  `iosSimulatorArm64` — all under one `com.github.binayshaw7777:KotStep:3.2.0` coordinate;
  platform variants resolve automatically via Gradle module metadata.
- **Android-free `commonMain`**: the V3 public API now lives in `commonMain` (package
  `com.binayshaw7777.kotstep.v3`) and hosts zero `android.*` imports.
- **Shared demo app**: desktop, web, and iOS entrypoints render the same `DemoApp` built
  from the shared `:demo` module.
- **Testing**: 25 automated tests (shared pure-logic tests + `desktopTest` compose UI tests;
  Android on-device instrumented tests retained). GitHub Actions `cmp-ci` matrix builds
  android / desktop / web / iOS.
- **Hardening**: RTL-correct line padding, 48dp interactive targets, `Role.Button` semantics
  on stepper items, Kotlin/Native linkage verified for iOS frameworks.

## Deprecation

- The **V2 sealed-class API** is deprecated (WARNING) but remains fully functional and
  **Android-only** for the entire 3.x line. Migrate to the V3 DSL; see the
  [deprecation ADR](../../docs/decisions/2026-09-14-v2-deprecation.md). Removal planned for v4.

## Migration notes (Android consumers)

1. JitPack coordinate is unchanged: `com.github.binayshaw7777:KotStep:3.2.0`.
2. V3 import is `com.binayshaw7777.kotstep.v3.KotStep`; annotate with
   `@OptIn(ExperimentalKotStep::class)`; `currentStep` is a required `() -> Float`.
3. V2 symbols remain available from `androidMain`.

## Known limitations

- iOS consumers get the framework via Xcode integration / GitHub Releases binaries; JitPack
  serves metadata + klibs (linking happens at the app side).
- Web consumers use the published web demo; the Wasm klib is published for progressive use.
